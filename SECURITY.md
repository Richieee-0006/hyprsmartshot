# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `0.0.1` | :white_check_mark: |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in HyprSmartShot, please report it responsibly:

1. **Do not disclose publicly** in public GitHub issues or discussions.
2. Submit a report privately via **GitHub Security Advisories** at:
   https://github.com/Richieee-0006/hyprsmartshot/security/advisories/new
   or contact the maintainer directly.

We appreciate your efforts in keeping open-source software safe!
